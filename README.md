## 🟢 Microsoft Excel | Análise de Dados e Indicadores

O Excel é uma das ferramentas que utilizo para organizar informações, realizar cálculos, analisar resultados e criar visualizações que facilitam a interpretação dos dados.

Nesta seção, compartilho análises desenvolvidas em atividades acadêmicas e exercícios práticos.

<details>
  <summary><strong>📉 Análise 01 — Regressão Linear: Horas de Estudo e Notas</strong></summary>

  <br>

  **Sobre o projeto**

  Uma análise da relação entre o tempo dedicado aos estudos e as notas obtidas pelos estudantes.

  A proposta é investigar se estudantes que dedicam mais horas aos estudos tendem a apresentar notas maiores, utilizando um gráfico de dispersão e uma linha de tendência linear.

  **O que foi utilizado:**
  - Gráfico de dispersão.
  - Regressão linear.
  - Equação da reta.
  - Coeficiente de determinação (R²).

  **Ferramenta:** Microsoft Excel.

  **Fonte dos dados:** [Student Result Analysis — GitHub](https://github.com/Sainathmudigonda/Student-Result-Analysis/blob/main/student_exam_scores.csv).
